- 변수 모드를 풀지 않아 다크 프레임의 컴포넌트 안 글자·채우기는 라이트 기본값으로 그려진다. 다크 PNG는 배치만 보고, 색은 라이트 PNG와 DesignKit 토큰으로 본다.

- More·S13-0 설정 홈 분리, More B 로그인 카드의 팩 목록 유지·계정 줄 숨김, More C 빈 카드 "페스티벌 둘러보기", More D 내 깃발 카드, 기수 카드 새 설명 "깃발 프로필을 만들면 바로 기수로 시작해요": 화면 구조와 라우팅이 바뀌는 큰 변경이라 이번 묶음에서 보류했다.
