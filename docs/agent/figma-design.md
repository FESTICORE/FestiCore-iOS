# Figma 디자인 대조

- 대조 기준은 `Tools/FigmaExportPlugin`(Codex가 만든 Figma 플러그인)으로 추출한 프레임 PNG·JSON이다. JSON의 `figmaRest`에서 텍스트 스타일, 간격, 색 토큰, 컴포넌트 인스턴스 이름을 읽는다.
- 원본 파일은 보기 권한이라 내 초안의 복사본에서 플러그인을 실행한다. 디자인이 갱신되면 복사본에 최신 디자인을 반영한 뒤 다시 추출하고, 이전 추출본과 바뀐 프레임을 비교한다.
- 라이트와 다크 프레임을 모두 대조한다. 시뮬레이터 외관을 바꿔 전후 캡처를 남긴다.
- 색·간격·글꼴은 DesignKit 토큰과 컴포넌트로만 맞춘다. Bagel Fat One 글꼴은 쓰지 않는다. DesignKit 자체가 Figma와 다르면 iOS에서 고치지 않고 차이를 보고한다(원천은 `FestiCore-DesignSystem` 저장소).
- 기능이 없는 버튼이나 화면을 디자인만 보고 추가하지 않는다. 필요한 기능은 이슈로 남긴다.
