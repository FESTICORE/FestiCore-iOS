# 팝업과 모달

현재 FestiCore에는 공통 Alert·Toast·Modal 컴포넌트가 없다.

새 화면에서 팝업이 필요하면 기본 SwiftUI presentation을 먼저 검토하고, 공유가 필요한 동작만 `Projects/UI/FestiCoreSharedUI`에 둔다. 표현 상태는 화면 기능이 소유하고, 네트워크·저장소 오류를 사용자에게 보여주는 문구는 호출 기능에서 결정한다. 접근성 포커스, 닫기 동작, 중복 표시를 화면 테스트에서 확인한다.

디자인 토큰과 컴포넌트 사양이 확정되면 이 문서에 실제 API와 사용 예를 추가한다.
