# 성능 작업 통합 흐름

성능 관련 문서는 [성능 점검](ios-performance-optimization.md), [개선 흐름](ios-performance-optimizer.md), [Point-Free 관점](ios-performance-pfw.md)으로 나뉜다.

문제 화면이나 모듈을 지정하고 재현 → 측정 → 작은 수정 → 재측정 순서로 작업한다. 화면 렌더링과 비동기 작업처럼 원인이 다르면 측정 결과에 맞춰 담당 코드를 구분한다. 실제 성능 수치가 없는 상태에서는 개선율을 주장하지 않는다.

성능 수정 후에는 관련 테스트와 빌드를 실행하고, 기능 동작과 측정 결과를 별도로 보고한다.
