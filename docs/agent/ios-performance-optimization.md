# iOS 성능 점검

현재 앱은 iOS 18 이상을 대상으로 한다. 성능 문제는 측정 지점을 먼저 정하고 재현한 다음 변경 전후를 같은 기기·구성에서 비교한다.

1. 화면 끊김은 실제 화면과 데이터량으로 재현하고, 렌더링·이미지 디코딩·메인 액터 작업을 나눠 확인한다.
2. 네트워크 지연은 요청 횟수, 캐시 정책, 재시도 및 토큰 갱신 흐름을 확인한다.
3. 메모리 증가는 화면 전환, 구독·작업 취소, 이미지 캐시 수명을 확인한다.
4. 빌드 성능은 Tuist 타깃 의존성과 변경 범위를 확인한다.

다른 앱의 화면 성능 수치나 에이전트 호출 규칙은 이 프로젝트의 측정 결과가 아니다. 개선은 측정 근거와 회귀 검증을 함께 기록한다.
