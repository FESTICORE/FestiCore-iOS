- 실제 등록 family: systemSmall/Medium/Large, accessoryInline/Circular/Rectangular. 모든 시안 크기는393pt 기기 예시이며 시스템 크기 우선.

- 위젯은 기존 App Group snapshot/팩을 사용하고 직접 서버 호출하지 않음. 이번 변경은 저장·갱신·딥링크 계약을 바꾸지 않음.
